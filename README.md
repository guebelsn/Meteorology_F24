# Meteorology_F24
Weather and Climate notebooks used at Santa Barbara City College (SBCC), Fall 2024. This includes 2 interactive jupyter notebook assignments. 
The notebooks follow the same format used in SBCC’s Data Science course, CS/MATH 118 (Data Science for All), which is modeled after UC Berkeley’s Data 8 course.
