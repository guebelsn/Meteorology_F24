# Meteorology_F24
**GEOG/ERTH 152** *(Weather and Climate)* course notebooks used at Santa Barbara City College (SBCC), Fall 2024. This includes 2 interactive jupyter notebook assignments. 
The notebooks follow the same format used **CS/MATH 118** *(Data Science for All)*, a foundation in Data Science course modeled after UC Berkeley’s Data 8 course.
